Make sure your JDK version is JDK24, NetBeans IDE25

to check your JDK version
Open your command line interface:
Windows: Press Win + R, type cmd, and press Enter.
macOS/Linux: Open the Terminal application.
    "javac -version"
This is the download link for JDK-24:
https://download.oracle.com/java/24/latest/jdk-24_linux-aarch64_bin.tar.gz

to check your NetBeans IDE version, click "help" from the upper left corner of the NetBeans then click "About"
then it will display the IDE version of the NetBeans
This is the download link for NetBeans IDE 25:
https://netbeans.apache.org/front/main/download/nb25/

First open project from NetBeans,
Then, Locate the Source Packages, then open the "control" file and locate the "main" file to run the program

For more details, please refer to the Documentations.
